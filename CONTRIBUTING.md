# Contributing to AndroFile

Thanks for helping improve AndroFile.

## Before opening an issue

- Check whether the issue already exists.
- Include your device model and Android version.
- Describe the exact steps to reproduce the issue.
- Include a short, redacted log excerpt when relevant. Never attach private files or personal data.

## Pull requests

- Keep changes focused.
- Preserve the SAF permission model unless a change has been reviewed carefully.
- Do not claim support for an archive format or storage location until it has been tested on-device.
- Add or update tests when changing path handling or archive extraction.
- Explain any new permission in the pull request description.

## Design direction

AndroFile aims for a clean, tactile interface: considered spacing, legible hierarchy, restrained gradients, distinct file-type cues, and motion that helps explain state changes. Avoid decorative controls that do not perform a real action.
